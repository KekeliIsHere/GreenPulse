# GreenPulse
GreenPulse is an AI-powered crop disease detection web application that uses a trained deep learning model to identify crop diseases of maize, tomato, and cocoa across from leaf images.Where users can upload an image or capture an image using their device camera, then it processes the image and provides a predicted crop condition and confidence score showing how confident of its answer.

## Features
- Upload crop leaf images / Capture images using a device camera
- AI-based crop disease detection
- Prediction confidence score
- Multi-language UI support (English, Twi, Ga, Ewe)
- Streamlit web interface

## Technologies
- The technological tools we used are Python, PyTorch, Torchvision, Streamlit, Pillow, NumPy

## Requirements
Before installing GreenPulse, make sure you have:
- Python 3.10 or newer
- pip
- Git (optional)

Check your Python version in the git bash by typing python --version

## Installation of the application and necessary files(everything being typed is done in the git bash )

### 1. Clone the Repository
Clone the GreenPulse repository by typing: git clone <repository-url>

Then move into the project folder by typing: cd GreenPulse

If you already have the project downloaded, you can skip this step and open your terminal inside the GreenPulse project folder.

### 2. Create a Virtual Environment
Create a virtual environment for the project by typing:  python -m venv .venv

### 3. Activate the Virtual Environment
For git bash you activate the environment by typing : source .venv/Scripts/activate

For Windows Command Prompt you activate the environment by typing:
```cmd
.venv/Scripts/activate
```

For Windows PowerShell you activate the environment by typing:
```powershell
./.venv/Scripts/Activate.ps1
```

Note: If PowerShell prevents the activation script from running, use Command Prompt instead.

### 4. Install the Dependencies
After you activate the virtual environment, install the required packages by typing:  pip install -r requirements.txt

If the `requirements.txt` file is not available, the main packages can be installed  by typing:   pip install torch torchvision streamlit pillow numpy

## Running the Application
Make sure the virtual environment is activated and that you are inside the main GreenPulse project folder.
Then run the Streamlit application by typing: streamlit run app/app.py
After running the command, Streamlit will provide a local URL in the terminal and the application can usually be accessed at:
http://localhost:8501
Open the URL in a web browser to use GreenPulse.

## Using GreenPulse
1. Open the GreenPulse application.
2. Upload a crop leaf image or capture an image using your device camera.
3. Click the **Detect Disease** button.
4. Wait for the image to be processed.
5. View the predicted crop condition.
6. View the confidence score.

## Troubleshooting

### Streamlit is not recognized
If you receive an error saying that `streamlit` is not recognized, make sure your virtual environment is activated.

You can install Streamlit manually by typing:  pip install streamlit

Then run: streamlit run app/app.py

### PyTorch is not installed
If you receive the error ModuleNotFoundError: No module named 'torch'  then install PyTorch by typing pip install torch torchvision

You can check that PyTorch is installed by typing python -c "import torch; print(torch.__version__)"

### Model Not Found
If the application cannot find the trained model, check that the following file exists:  models/custom_greenpulse_model.pth
Also make sure that you are running the Streamlit command from the main GreenPulse project folder.

### PowerShell Activation Error
If PowerShell reports that script execution is disabled, use Git bash instead by typing: source .venv/Scripts/activate
Then run by typing streamlit run app/app.py

### Missing Dependencies
If the application reports that a Python package is missing, run: pip install -r requirements.txt
